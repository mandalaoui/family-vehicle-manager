# רשימת בדיקות בטלפון: Phase 2

לפני הבדיקה: להריץ את מיגרציה 6 (`supabase/migrations/20261118100000_phase2_features.sql`) ב־SQL Editor של פרויקט Supabase החדש, ולוודא שהפריסה ב־Vercel הסתיימה.
שני משתמשי Google לבדיקה: **א** (מנהל) ו־**ב**. כדאי גם משתמש **ג** חדש לגמרי, שמעולם לא התחבר לאפליקציה.

## 1. משתמש חדש לגמרי (הרשמה פתוחה)

- [ ] ג׳ פותח את האתר, לוחץ ״התחברות עם Google״ ומתחבר. מגיע למסך ״ברוכים הבאים״ (לא ללוח ריק).
- [ ] ג׳ יוצר משפחה ״משפחת בדיקה״, ומגיע ללוח עם ההודעה ״עדיין אין רכבים במשפחה״.
- [ ] ג׳ לוחץ ״הוספת רכב״, מקליד מספר רכב אמיתי, והפרטים מתמלאים לבד. אחרי שמירה הרכב מופיע בלוח.
- [ ] ג׳ לא רואה את המשפחה או הרכבים של א׳.
- [ ] ניסיון לפתוח משפחה שנייה (למשל לחזור ל־`/onboarding` ידנית) מחזיר אותו ללוח.

## 2. הזמנה: משתמש חדש שפותח את הקישור לפני שהתחבר

- [ ] א׳ מזמין כתובת Google של משתמש ד׳ (חדש, שמעולם לא התחבר) מ־הגדרות, ומעתיק את הקישור.
- [ ] ד׳ (לא מחובר, מכשיר נקי או גלישה בסתר) פותח את הקישור. רואה ״הוזמנתם להצטרף ל…״ וכפתור התחברות.
- [ ] אחרי ההתחברות ד׳ חוזר לדף ההזמנה, לוחץ ״הצטרפות למשפחה״ ונכנס ללוח של א׳. הוא לא הופנה ליצירת משפחה.
- [ ] ד׳ רואה את הרכבים של המשפחה, כחבר ללא כפתור ״הוספת רכב״.
- [ ] הקישור כבר נוצל: פתיחה שנייה מציגה ״ההזמנה כבר נוצלה״.

## 3. הזמנה: משתמש שנכנס בלי הקישור

- [ ] א׳ מזמין את ה׳ (חדש). ה׳ מתחבר ישירות לאתר, בלי הקישור.
- [ ] במסך ״ברוכים הבאים״ ה׳ רואה למעלה ״הוזמנתם להצטרף למשפחה״ עם כפתור ״להצטרפות למשפחה״, ואפשרות יצירת משפחה נפרדת מתחת.
- [ ] לחיצה על הכפתור מצרפת אותו למשפחה של א׳.
- [ ] משתמש שאין לו הזמנה לא רואה את הקטע הזה.
- [ ] משתמש שכבר חבר במשפחה שפותח קישור הזמנה אחר רואה ״החשבון הזה כבר חבר במשפחה״ ולא כפתור הצטרפות.

## 4. מצבר

- [ ] בעריכת רכב, בקטע ״מצבר וצמיגים״: תאריך החלפה (למשל לפני 35 חודשים), תוקף אחריות והערות. שמירה מצליחה.
- [ ] בפרטי הרכב מופיע כרטיס ״מצבר״ עם תאריך ההחלפה, התווית **הערכה** וסטטוס (״בקרוב״ כשנשארו עד 30 יום).
- [ ] תאריך החלפה עתידי נדחה בהודעה ברורה. מרווח 0 חודשים נדחה.
- [ ] שינוי המרווח ל־6 חודשים מעדכן את ההערכה. בלוח מופיעה התראה ״בדיקת מצבר (הערכה)״ כשהיא קרובה.

## 5. צמיגים

- [ ] תאריך החלפה אחד + ק״מ בהחלפה: בפרטי הרכב מופיעים התאריך, הק״מ ותווית **הערכה**.
- [ ] ק״מ בהחלפה גבוה מהק״מ הנוכחי נדחה בהודעה.
- [ ] הדלקת ״תאריך נפרד לכל גלגל״ מציגה ארבעה שדות (קדמי ימני, קדמי שמאלי, אחורי ימני, אחורי שמאלי). ההערכה נספרת מהגלגל הישן ביותר.
- [ ] כיבוי המתג מחזיר לתאריך אחד.
- [ ] בלי ק״מ בהחלפה התזכורת היא לפי חודשים בלבד. עם ק״מ, ברכב שעבר 50,000 ק״מ מההחלפה מוצג ״באיחור״ גם אם התאריך רחוק.

## 6. מוסכים

- [ ] בתפריט (המבורגר בנייד) יש ״מוסכים״. מסך ריק מציג הסבר.
- [ ] חבר רגיל (לא מנהל) מוסיף מוסך עם שם, טלפון, כתובת והערות. המוסך מופיע ברשימה.
- [ ] שם כפול (גם באותיות אחרות) נדחה ב־״מוסך בשם הזה כבר קיים״. טלפון לא תקין נדחה.
- [ ] ״התקשרות״ פותח את חייגן הטלפון עם המספר.
- [ ] ״נווט ב־Waze״ פותח את Waze (או את האתר) עם חיפוש הכתובת. ״פתח במפות״ פותח Google Maps.
- [ ] ללא כתובת, הניווט מחפש לפי שם המוסך.
- [ ] חבר רגיל לא רואה ״מחיקה״ בתפריט ⋯. מנהל כן, ובאישור המחיקה מוצגת ההסבר על הטיפולים הקיימים.
- [ ] בעת ״בוצע טיפול״ מופיעה רשימת ״מוסך מהרשימה״. בחירה בה שומרת את הטיפול עם שם המוסך.
- [ ] מחיקת מוסך שקושר לטיפול משאירה את הטיפול עם שם המוסך.
- [ ] מחיקת טיפול ואז ״ביטול״ בהודעה מחזירה אותו עם אותו מוסך.

## 7. התנהגות כללית ונגישות בנייד

- [ ] בכל המסכים (לוח, רכבים, פרטי רכב, עריכה, מוסכים, הגדרות, הזמנה) אין גלילה אופקית, בטלפון קטן (360px) ובינוני (390px).
- [ ] כל הכפתורים והקישורים נוחים ללחיצה באגודל. המבורגר פותח ונסגר ב־Escape/לחיצה בחוץ.
- [ ] חלונות (טיפול, קילומטראז׳, מוסך) נפתחים מלמטה כ־bottom sheet ואפשר לגלול בתוכם כשהמקלדת פתוחה.
- [ ] כיוון RTL תקין: מספרים, לוחיות וטלפונים מוצגים משמאל לימין בתוך הטקסט.
- [ ] טאבלט (768px) ומחשב: הניווט מוצג כטאבים בראש הדף, בלי חפיפות.

## 8. ביצועים (תחושה)

- [ ] מעבר בין לוח, רכבים ופרטי רכב מרגיש מהיר יותר מקודם (בפרט פתיחת הלוח אחרי התחברות).
- [ ] פתיחת פרטי רכב מציגה שלד טעינה ולא מסך לבן.
